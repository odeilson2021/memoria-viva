# SKILLS DISPONÍVEIS (carga sob demanda)

Cada skill abaixo tem seu corpo detalhado em `intelligence/skills/<arquivo>.md` (copiado para `.agent/skills/` no projeto alvo). O agente carrega o corpo **somente ao acionar** a skill.

| Skill | Gatilho (1 linha) — ative quando a tarefa envolver: |
|-------|------------------------------------------------------|
| `software-architect` | Arquitetura, camadas, DI/IoC, escalabilidade, decisão de estrutura de pastas. |
| `code-reviewer` | Revisão de PR, debug por evidência, anti‑retrabalho, checklist de qualidade. |
| `database-dba` | Schema, índices, N+1, transações, Repository, paginação, charset. |
| `security-expert` | OWASP, sanitização, CSRF/XSS, sessões `auth_sessions`, secrets. |
| `ui-ux-designer` | Respeitar `DESIGN_SYSTEM.md`, reaproveitar componentes, a11y, responsivo. |

> Regra da 2ª vez: se uma tarefa se repetir, converta‑a em skill reutilizável em vez de repetir o procedimento.
